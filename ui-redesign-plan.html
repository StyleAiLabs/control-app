UI Redesign Plan Sync360 Brand Alignment

Design critique + component-by-component spec for updating all 13 Blade templates

Core Problem: This UI speaks to developers, not customers. Every screen contains internal MVP language — "Local-first tenant provisioning MVP", "Blade-first control plane", "Flow Proof", "Session auth is intentionally simple for this MVP". The colours are green (#0f8c6f) — the Sync360 brand is orange (#FF6B35). The font is IBM Plex Sans — Sync360 uses DM Sans. Before a single customer sees this, the whole UI needs to be reframed from internal prototype to premium product.

Implementation Sprint Plan

Sprint 1 — Brand Token Fix (2–3 hours) · Highest impact, lowest risk

Change the CSS variables in both layout files. This single change propagates across all 13 templates instantly — buttons, links, focus rings, badges, eyebrows all flip from green to orange.

layouts/guest.blade.php layouts/app.blade.php
Changes: --accent: #0f8c6f → #FF6B35 · --accent-dark: #0a5e4c → #e55a25 · font-family: IBM Plex Sans → DM Sans · Add Google Fonts import for DM Sans + Space Mono · Fix button gradient → solid orange · Fix background tint → warm neutral

Sprint 2 — Copy Rewrite (3–4 hours) · Transforms customer perception

Rewrite all customer-facing copy to remove MVP/developer language and replace with Sync360's direct, benefit-led tone. No code changes — pure content.

landing.blade.php auth/signup.blade.php auth/login.blade.php dashboard.blade.php tenant/setup.blade.php tenant/workspace-ready.blade.php
Changes: All headlines, sub-copy, stat labels, progress messages, mini-tile content, form hints. Remove every reference to "MVP", "tenant record", "provisioning job", "worker", "Docker", internal paths.

Sprint 3 — Dashboard Data (2–3 hours) · Makes it feel like a real product

Replace raw DB field values with human-friendly labels and remove internal system details from customer-facing views.

dashboard.blade.php tenant/workspace-ready.blade.php

Sprint 4 — Landing Page Enhancement (4–6 hours) · Full brand expression

Rebuild the landing page hero section with Sync360's dark-background / orange-accent aesthetic. Replace tech stats with customer benefit stats. Replace dev-diagram visual with a product preview mockup.

landing.blade.php layouts/guest.blade.php
